# 上游站点与价格调度

后台「站点管理」支持 Sub2API、New API。填写站点首页地址和后台登录凭据，保存后获取可用分组、模型和价格。登录凭据使用现有 SecretEncryptor 加密，列表与错误响应不返回密码、Token 或上游 Key。支持密码、Access Token、Refresh Token；需要验证码或二次验证的站点先在上游完成登录，再提供令牌。

绑定选择「上游分组 + 模型 → 本地分组 + 模型别名」，设置采购单价上限。每个绑定自动创建一个独立上游 Key 和本地 API Key 账号。上游 Key 用绑定 UUID 命名，创建超时后重试先查找已有 Key。Sub2API Key 固定分组；New API Key 同时限制模型并关闭跨分组重试。本地托管账号的凭据、分组和模型映射由站点管理维护。

一个模型绑定对应一个账号，1K、2K、4K 是该账号内的独立价格档位。超价只排除对应档位；请求分辨率未知或为自动时要求所有分辨率均符合上限。价格下降后下一次成功同步自动恢复，手工暂停账号不会被价格恢复覆盖。

## 同步与价格口径

- 后台每分钟检查到期任务，每次同步后安排 5 分钟后的下一次同步；页面支持「立即同步」。成功价格有效期 10 分钟，短暂同步失败保留未过期价格，过期后停止调度。
- 价格包含上游个人/分组倍率。Sub2API 图片独立倍率、上下文阶梯、分时/高峰、最高推理倍率按已公开字段处理；上下文与分时价格采用最高单价作为保守上限。
- USD/次、USD/张、USD/百万 token 分开比较。输入、输出、缓存和其他公开成本分量分别设置上限，缺失值不视为免费。
- New API 支持固定按次价格、token 倍率，以及可安全归约的非负线性计费表达式（条件分支取各分量最高值）。复杂任务插件、非线性规则或不完整价格显示不可核价并暂停调度。额外服务档位（priority/fast/flex 等）尚未单独核价，托管账号不会承接这类请求。
- Sub2API 需要上游启用模型广场；无法获得完整价格时明确提示。模型改名或下架不会自动猜测替换关系，需要重新绑定到本地别名。
- 站点目录、绑定账号价格策略和调度缓存失效事件在一个 PostgreSQL 事务中发布。请求调度及每次实际发送（含重试）均检查价格；已付费结果的 GET 下载不受新涨价影响。
- 保留最近 100 条价格变化。解除绑定删除本地托管账号，上游 Key 保留；删除站点须先解除全部绑定。

五分钟轮询无法感知两次扫描之间的即时涨价；本功能依赖上游发布的价格，也不自动推算充值折扣、汇率或本地销售利润。

## 预览与发布

6556 仍复用生产 PostgreSQL、JWT、现有管理员及业务数据，Redis 保持独立 DB 14。预览服务必须设置 `UPSTREAM_SITES_PREVIEW=true`：停用自动同步任务，新建托管账号以停用状态保存，避免旧生产程序在没有新价格保护的情况下调度它们。预览可以手动同步和绑定；绑定会真实创建上游 Key 和本地账号。

用户确认上线后，按 `ops/README.md` 发布已提交并推送的版本。生产服务不设置预览变量，首次同步后会激活标记为待发布的托管账号。已有手动暂停账号不会被自动启用。

## 验证

服务测试使用本地 HTTP 上游桩，覆盖密码加密、令牌轮换、Key 超时恢复、价格上涨/回落、过期与逐次重试检查；调度测试同时覆盖普通与高级调度器、独立分辨率过滤。仓库集成测试用专用 PostgreSQL/Redis 容器验证事务、迁移、锁与缓存失效，不向生产库写测试数据。前端测试覆盖分辨率独立上限、模型别名、凭据不回填及同步错误显示。
